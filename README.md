# Al-Esnad Academy — Landing Page

موقع HTML/CSS/JS جاهز مبني على التصميم المرفق لمؤسسة الإسناد الأكاديمي في أوغندا.

## التشغيل
1. افتح `index.html` مباشرة في المتصفح، أو شغّل مجلد الموقع عبر أي static server.
2. لا توجد مكتبات JavaScript خارجية.
3. الصور المستخدمة موجودة داخل `assets/`.

## ملاحظات
- زر English يبدّل اتجاه الصفحة RTL/LTR.
- نموذج التواصل والنشرة البريدية يعملان بوضع تجريبي ويحتاجان ربطاً بخدمة backend أو بريد عند الإطلاق.
- بيانات الهاتف والبريد والموقع أمثلة قابلة للتعديل.
